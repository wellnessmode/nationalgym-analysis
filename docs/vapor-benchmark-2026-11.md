# VAPOR 벤치마킹 · 우리 앱 측정 신뢰도 진단

작성 2026-11-21 · 대상 `motion-beta.html` v2.1.1-beta

표기: **확인** = 출처에서 직접 확인 / **추론** = 확인된 사실에서 논리적으로 도출 / **미확인** = 단서만 있음.
VAPOR 공식 사이트·앱스토어 본문은 이 작업 환경에서 직접 열 수 없어, VAPOR 관련 "확인"은 서로 다른 검색 결과 2건 이상에서 같은 원문이 반복된 경우를 뜻합니다.

## 1. 결론

1. **VAPOR가 정확해 보이는 이유는 더 좋은 AI가 아니라 "재는 대상"이 다르기 때문입니다.** VAPOR는 점프 높이(cm), 횟수, 버틴 시간(초), 100°대의 큰 각도를 잽니다. 우리는 어깨·골반이 1~3° 기울었는지를 잽니다. 카메라 포즈 인식의 오차는 어느 쪽이든 ±1~2°로 같은데, 103°에서 2°는 2%이고 3° 기준에서 2°는 67%입니다.
2. **우리 앱의 편차는 실측으로 확인됩니다.** 같은 사람·같은 자세 사진을 서는 위치와 거리만 바꿔 30번 넣으면 골반 기울기가 최대 1.9° 벌어지고, 폰이 ±2° 기울면 어깨 기울기가 5.2° 벌어집니다. 판정 기준은 3°입니다. 같은 사진을 좌우 반전만 해도 골반 기울기가 0.2°에서 3.7°로 바뀝니다.
3. **모델을 더 큰 것으로 바꿔도 해결되지 않습니다.** lite·full·heavy 세 모델 모두 편차가 같은 수준이고, 같은 사진에 대해 세 모델이 서로 다른 답을 냅니다.
4. **VAPOR도 검증된 제품은 아닙니다.** 직원 6명 규모, 센터용 앱 다운로드 100+, 공개된 정확도 검증 자료 없음. 대표님이 보신 게시물에는 인스타그램의 "AI 콘텐츠" 표시가 붙어 있습니다.
5. **고치는 방향은 네 가지입니다.** (가) 촬영 조건을 앱이 강제, (나) 지표를 신뢰 등급으로 나눠 작은 각도는 숫자 대신 구간으로, (다) 큰 각도·횟수·시간 중심으로 재편, (라) 재현성 테스트를 통과해야 배포. 상세는 5장.

## 3. 우리 앱 실측 — 재촬영 재현성 실험

### 3.1 방법

실제 사람의 정면 전신 사진 1장(MediaPipe 공개 테스트 사진, 검은 상의·청바지)을 세로 카메라 프레임(720×1280)에 배치하고, **자세는 그대로 둔 채** 아래 조건만 바꿔 30번씩 넣었습니다. 자세가 같으므로 참값은 변하지 않고, 값이 달라진 만큼이 전부 측정 오차입니다. 지표는 앱의 실제 `calcM()` 함수로 계산했습니다.

- B: 같은 프레이밍 + 눈에 안 보이는 수준의 센서 노이즈
- C: 재촬영 — 서는 위치 ±5%, 거리(인물 크기 72~98%), 조명 ±20%
- D: C + 폰 기울기 ±2°
- F: 라이브 추적(앱의 실시간 화면과 같은 방식) 프레임 간

실제 현장은 여기에 자세 흔들림, 옷 주름, 카메라 높이 차이, 렌즈 왜곡이 더해지므로 **아래 수치는 가장 좋은 경우의 하한**입니다. 사진 1장 기준이라 사람·옷에 따라 수치는 달라집니다. 재실행: `node tools/repeat-test/run.js`

### 3.2 결과 — 작은 각도 지표 (판정 기준 3°)

표준편차 / 범위(최대−최소), 단위 °, N=30

| 모델 | 조건 | 어깨 기울기 | 골반 기울기 | 체간 기울기 |
|---|---|---|---|---|
| lite | B 노이즈만 | 0.16 / 0.7 | 0.23 / 1.2 | 0.13 / 0.5 |
| lite | C 재촬영 | 0.35 / 1.3 | 0.41 / 1.8 | 0.22 / 0.8 |
| lite | D 재촬영+폰 ±2° | **1.41 / 3.9** | **1.51 / 5.2** | **1.38 / 4.7** |
| full | B 노이즈만 | 0.27 / 1.1 | 0.24 / 0.9 | 0.14 / 0.6 |
| full | C 재촬영 | 0.36 / 1.5 | 0.46 / 1.9 | 0.25 / 1.0 |
| full | D 재촬영+폰 ±2° | **1.44 / 5.2** | **1.21 / 4.4** | **1.36 / 4.7** |
| heavy | B 노이즈만 | 0.25 / 1.0 | 0.22 / 0.9 | 0.12 / 0.5 |
| heavy | C 재촬영 | 0.36 / 1.4 | 0.60 / 3.0 | 0.21 / 0.9 |
| heavy | D 재촬영+폰 ±2° | **1.40 / 4.4** | **1.29 / 5.0** | **1.30 / 4.2** |

읽는 법:
- 카메라가 완벽히 수평이어도(C) 골반 기울기는 1.8~3.0° 범위로 벌어집니다. 3° 기준 근처의 회원은 찍을 때마다 정상/이상이 바뀝니다.
- 폰이 ±2° 기울면(D) 범위가 4~5°가 됩니다. **폰 기울기가 지표에 그대로 더해지기 때문입니다.**
- heavy 모델이 lite보다 나은 점이 없습니다.

### 3.3 같은 사진인데 답이 다른 경우

| 실험 | 결과 |
|---|---|
| 같은 사진, 모델만 교체 | 어깨 기울기 lite −0.5° / full −1.4° / heavy −0.4°, 골반 기울기 2.2° / 1.3° / 2.7° |
| 같은 사진, 좌우 반전 후 다시 측정(full) | 골반 기울기 0.15° → 3.69°, 어깨 기울기 −1.40° → −0.45° |
| 같은 사진, 좌우 반전 후 다시 측정(heavy) | 어깨 기울기 +1.26° → −1.75° (방향이 뒤집힘) |
| 라이브 추적 vs 사진 1장(lite) | 골반 기울기 라이브 4.1° / 사진 2.2° |

원리: 포즈 모델(BlazePose)은 전신을 256×256 픽셀로 줄여서 봅니다. 이 실험의 인물 크기로 환산하면 모델이 보는 어깨 폭은 약 40픽셀, 골반 폭은 약 25픽셀입니다(추정). **골반점 하나가 1픽셀 어긋나면 약 2.3°, 어깨점은 약 1.5°가 변합니다.** 3° 기준은 모델 해상도로 1~2픽셀 차이를 판정하는 셈이고, 카메라 해상도를 올려도 이 한계는 그대로입니다.

라이브 화면이 주는 착시: 라이브 추적 중에는 프레임 간 표준편차가 0.01~0.1°로 매우 안정적으로 보입니다(F). 추적기가 이전 프레임 위치를 이어받기 때문입니다. 화면에서는 숫자가 흔들리지 않으니 정확해 보이지만, 다시 찍으면 다른 값에 고정됩니다. "화면에선 멀쩡한데 찍을 때마다 다르다"는 현장 피드백과 일치합니다.

### 3.4 대조군 — 큰 각도 지표

같은 조건, full 모델, 표준편차 / 범위

| 지표 | 평균 | C 재촬영 | D 재촬영+폰 ±2° | 값 대비 표준편차 |
|---|---|---|---|---|
| 무릎 굽힘(런지 자세) | 105.5° | 1.46 / 5.7 | 1.51 / 6.0 | 1.4% |
| 어깨 외전(팔 수평) | 94.5° | 0.71 / 2.5 | 1.45 / 6.0 | 0.8~1.5% |
| 팔꿈치 굽힘 | 69.8° | 1.09 / 4.2 | 0.87 / 3.5 | 1.6% |
| 어깨 외전(팔 내림) | 20.8° | 0.26 / 1.2 | 1.22 / 4.2 | — |
| (비교) 골반 기울기 | 1.8° | 0.46 / 1.9 | 1.21 / 4.4 | **3° 기준의 15~40%** |

무릎 굽힘과 팔 수평은 두 번째 사진(옆으로 선 런지 자세, 인물이 프레임 높이의 16%로 작게 찍힌 불리한 조건)에서 잰 값입니다.

절대 오차는 큰 각도나 작은 각도나 비슷합니다(표준편차 0.3~1.5°). 차이는 **그 오차가 판정에 미치는 영향**입니다. 105°에서 ±1.5°는 결과를 바꾸지 않지만, 3° 기준에서 ±1.5°는 판정을 뒤집습니다. VAPOR가 고른 지표와 우리가 고른 지표의 차이가 이것입니다.

### 3.5 소프트웨어 보정만으로 얼마나 줄어드나

같은 캡처 프레임을 이동·확대·좌우 반전해 8번 인식한 뒤 관절별 중앙값을 내는 방식(촬영 횟수는 그대로)을 시험했습니다. 조건 C, 표준편차:

| 모델 | 어깨 기울기 | 골반 기울기 |
|---|---|---|
| lite | 0.42 → 0.24 | 0.48 → 0.32 |
| full | 0.34 → 0.24 | 0.57 → 0.55 |
| heavy | 0.36 → 0.18 | 0.47 → 0.35 |

어깨는 30~50% 줄지만 골반은 효과가 들쭉날쭉합니다. 도움은 되지만 이것만으로 3° 판정을 믿을 수 있게 되지는 않습니다. 촬영 조건 통제와 표시 방식 변경이 함께 필요합니다.
